# 用户定义变量

使用 `#DIM` 和 `#DIMS` 可以定义自定义变量。
在函数内定义的变量是只能在该函数内使用的私有变量，
在[头文件（ERH）](ERH.md)中定义的变量是可以从 ERB 中所有位置引用的广域变量。

## 格式（私有变量）

在要定义变量的函数声明下方写 `#DIM(S) <变量名>, <元素数>{, <元素数>{, <元素数>}}`。

`<变量名>` 是由非数字开头、仅包含 `_` 符号的任意字符串。
`<元素数>` 是 1～1000000 范围内的任意整数或常量表达式。省略时为 `1`。
根据给出的 `<元素数>` 数量，定义的变量维度会变化。最大为三维，不能定义四维及以上的变量。
`#DIM(S)` 定义的私有变量可以在单个函数中定义多个。

这样，由 `<变量名>` 指定名称的变量就可以在该函数内使用了。
变量可以按 `<元素数>` 指定的元素数赋值，不会被保存。初始值为 `0` 或空字符串。
用 `#DIM` 定义的是整数型变量，用 `#DIMS` 定义的是字符串型变量。
用 `#DIM(S)` 定义的变量也可以指定为该函数的参数。还可以设置初始值。

``` { #language-erbapi }
@FIND_CSTR(KEY, VALUE)
#FUNCTION
#DIM LCOUNT
#DIM KEY
#DIMS VALUE
SIF KEY < 0 || KEY >= VARSIZE("CSTR")
    RETURNF -1
FOR LCOUNT, 0, CHARANUM
    SIF LCOUNT == MASTER
        CONTINUE
    SIF CSTR:LCOUNT:KEY == VALUE
        RETURNF LCOUNT
NEXT
```

如上面的脚本所示，根据用途命名变量并设置适当的元素数，可以改善因不连续使用 `LOCAL` 导致的可读性下降。

## 初始值设置

声明一维数组变量时，可以定义初始值。
定义了初始值的数组可以省略元素数，此时初始值的数量自动成为数组的元素数。
如果不省略元素数，则该数字成为数组的元素数。
如果未省略元素数且初始值数量多于元素数，则会报错。

``` { #language-erbapi }
;省略元素数，HOGE 的元素数为 3
#DIM HOGE = 1,2,3

;不省略元素数，PUGE 的元素数为 100
#DIM PUGE,100 = 4,5,6

;错误（初始值数量多于指定的元素数）
#DIM HIGE,1 = 7,8,9

;字符串变量也可以（用字符串表达式指定）
#DIMS SHOGE = "A", "B", "C"
```

注意，多维数组不能定义初始值。

## 动态变量

在变量名前加 `DYNAMIC`，如 `#DIM(S) DYNAMIC <变量名>, <元素数>`，定义的变量将被动态分配。
具体来说，在函数被调用时分配，函数结束时变量及其值消失。
（[`RESTART`](../Reference/RESTART.md) 命令是"返回函数开头的命令"，因此即使是动态分配的变量也不会被重置）
即使在函数中调用（递归）自身，变量也会按递归次数分配，因此递归处理的行为是稳定的。
但是，操作速度比不加 `DYNAMIC`（静态变量）时慢。

## 常量

定义一维数组变量时，在变量名前加 `CONST`，可以定义一维数组常量。
与默认值一样，只能定义一维数组变量。
常量声明必须有初始值，且不能在中间通过赋值修改。
`CONST` 由于其性质，不能与 `GLOBAL`、`SAVEDATA`、`REF`、`DYNAMIC` 关键字同时使用。
也可以不省略数组元素数来指定，但如果元素数与初始值数量不一致则会报错。

``` { #language-erbapi }
;一维常量数组的定义
#DIM CONST HOGE = 1,2,3

;错误（初始值数量与元素数不一致）
#DIM CONST PUGE,100 = 4,5,6

;字符串变量也可以（用字符串表达式指定）
#DIMS CONST SHOGE = "A", "B", "C"
```

## 浮点变量（LazyLoading 扩展）

使用 `#DIMF` 可以定义浮点型变量。格式与 `#DIM` 相同。

``` { #language-erbapi }
;定义浮点变量
#DIMF F_VALUE = 1.5

;定义浮点数组
#DIMF F_ARR, 10

;浮点常量
#DIMF CONST PI = 3.14159265
```

浮点变量的初始值为 `0.0`。内置浮点变量包括 `LOCALF`、`ARGF`、`RESULTF`。
浮点函数使用 `#FUNCTIONF` 声明，通过 `RETURNF` 返回浮点值。

## 参照型变量

在变量名前使用 `REF` 关键字，可以定义参照型变量。
整数型 1～3 维数组和字符串型 1～3 维数组分别按以下方式声明：

``` { #language-erbapi }
#DIM REF HOGE1DIM,0
#DIM REF HOGE2DIM,0,0
#DIM REF HOGE3DIM,0,0,0
#DIMS REF PUGE1DIM,0
#DIMS REF PUGE2DIM,0,0
#DIMS REF PUGE3DIM,0,0,0
```

逗号数量匹配时 0 可以省略。一维数组时逗号也可以省略。
参照型变量没有实体，操作参照型变量时，实际操作的是通过 `REF` 命令（ver1.815 目前不可用）或引用传递传入的变量。
引用传递的详情请参阅[函数-参数的引用传递](../ExFunc/exfunc.md)。

### 标量引用（LazyLoading 扩展）

使用 `#REF` / `#REFS` 可以声明标量引用（Dimension=0），与 `#DIM REF` 数组引用彻底分离：

``` { #language-erbapi }
;整数标量引用
#REF L_REF

;字符串标量引用
#REFS L_SREF
```

`#REF L_REF` 声明整数标量引用（Dimension=0），`#REFS L_SREF` 声明字符串标量引用（Dimension=0）。
与 `#DIM REF L_ARR,0`（一维数组引用，Dimension=1）语义完全不同：
- 标量引用：引用单个值，读写直接代理到目标变量
- 数组引用：引用整个数组，通过索引访问元素

## OUT 参数（LazyLoading 扩展）

使用 `#DIM OUT` / `#DIMS OUT` 可以声明可省略的输出参数：

``` { #language-erbapi }
@PARSE_INPUT(RAW, OUT RESULT_CODE, OUT RESULT_TEXT)
#DIM RAW
#DIM OUT RESULT_CODE
#DIMS OUT RESULT_TEXT
; ...
```

OUT 参数的特性：
- 调用时可以省略，省略时绑定 `NullRefTerm` 黑洞变量（所有读写被静默忽略）
- OUT 与 `#REF` 同构（标量引用 Dimension=0），与 `#DIM REF` 不同构
- 支持 OUT + 可变参数组合、嵌套调用、CALLFORM/TRYCALL

``` { #language-erbapi }
;省略 OUT 参数调用
CALL PARSE_INPUT(RAW_VALUE)

;传递 OUT 参数
CALL PARSE_INPUT(RAW_VALUE, CODE, TEXT)
;此时 CODE 和 TEXT 会被写入
```

## 可变参数（LazyLoading 扩展）

使用 `VARIADIC` 关键字在函数签名的最后一个参数位置声明可变参数：

``` { #language-erbapi }
@SUM(VARIADIC ARG:0)
#DIM DYNAMIC _TOTAL
_TOTAL = 0
REPEAT ARGLEN()
    _TOTAL += ARG:COUNT
REND
RETURN _TOTAL

; 调用
CALL SUM(1, 2, 3)
PRINTVL RESULT
; 输出: 6
```

混合固定参数和可变参数时，固定参数应使用私有变量：

``` { #language-erbapi }
@GREET(PREFIX, VARIADIC ARGS:0)
; PREFIX 是私有变量固定参数，ARGS:0... 是可变字符串参数
PRINTFORM %PREFIX%:
REPEAT ARGLEN()
    PRINTFORM  %ARGS:COUNT%
REND
PRINTL
```

- `VARIADIC ARG:索引` — 整数可变参数
- `VARIADIC ARGS:索引` — 字符串可变参数
- `VARIADIC ARGF:索引` — 浮点可变参数
- `ARGLEN()` 内置函数返回可变参数的数量
- 可变参数必须是函数签名的最后一个参数
- 私有变量做固定参数时，ARG/ARGS 数组仅包含可变参数部分
- 支持 Int→Float 隐式转换

!!! warning "同类型参数约束"
    `@FUNC(ARG:0, VARIADIC ARG:1)` 会触发警告——同类型的 ARG 出现两次。
    应改用私有变量做固定参数：`@FUNC(L_val:0, VARIADIC ARG:0)`。

## 格式（广域变量）

在[头文件（ERH）](ERH.md)中写 `#DIM(S)` 时，与 ERB 中定义的私有变量不同，
是可以从 ERB 中所有位置引用的广域变量。
与私有变量不同的是，没有 `DYNAMIC` 和 `STATIC` 的区别，也不能用 `REF` 定义参照型变量，
但可以用 `CONST` 定义常量。
函数中的 `DIM` 没有的功能：可以定义保存的变量、全局变量和角色变量。
详情请参阅[头文件（ERH）](ERH.md)。

## 限制

### 不能使用与命令相同的名称

以下方式定义与命令同名的变量是不允许的：

``` { #language-erbapi }
;错误
#DIM PRINTFORM
#DIM SELECTCASE
#DIM CALL
#DIM RETURN
#DIM GOTO
#DIM SQRT
#DIM DATAFORM
#DIM NOSKIP
#DIM FUNC
#DIM ENDFUNC
```

可以定义与函数名和预处理器同名的变量，但不推荐。

``` { #language-erbapi }
;不推荐
#DIM EVENTFIRST
#DIM COMF32
#DIM COMABLE15
#DIM SHOW_ABLUP_SELECT
#DIM DIM
#DIM PRI
#DIM ONLY
#DIM SKIPSTART
```

### 函数外部的干扰

与 `LOCAL@HOGE` 中的 `LOCAL` 不同，没有办法引用或赋值其他函数的私有变量。

## `ERD(ERabasic Define)` 功能

EM+EE 中追加的功能。在 ERH 中定义的变量可以使用 `*.csv` 文件或 `*.ERD` 文件设置标识符，与 CSV 变量相同。

`ERH` 中定义的变量名为基准读取文件，可以像现有 `CSV` 变量一样给数组命名。
`CSV` 文件夹中可用的文件名为 `「变量名.csv」`，`ERB` 中可用的文件名为 `「变量名.ERD」`。格式与 `CSV` 变量的文件相同。如果两者都存在且定义了相同的标识符，启动时会报错终止。不同的标识符映射到相同的整数是允许的。
多维数组变量命名时，在文件名中加上 `@` 后跟数字来对应各维度。从左边的下标开始对应 `1`、`2`、`3`。

**ERH**

``` { #language-erbapi }
#DIM HOGE, 3
#DIM HOGE2D, 3, 3
#DIM HOGE3D, 3, 3, 3
```

**文件构成**

```
HOGE.ERD
HOGE2D@1.ERD
HOGE2D@2.ERD
HOGE3D@1.ERD
HOGE3D@2.ERD
HOGE3D@3.ERD
```
