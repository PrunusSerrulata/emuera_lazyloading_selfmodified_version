# SIN, COS, TAN, ASIN, ACOS, ATAN, FLOOR, CEIL, ROUND &#182;

| 函数名 | 参数 | 返回值 |
| :--- | :--- | :--- |
| **SIN** | int/float angle | 与参数类型对应的正弦值 |
| **COS** | int/float angle | 与参数类型对应的余弦值 |
| **TAN** | int/float angle | 与参数类型对应的正切值 |
| **ASIN** | int/float value | 与参数类型对应的反正弦值 |
| **ACOS** | int/float value | 与参数类型对应的反余弦值 |
| **ATAN** | int/float value | 与参数类型对应的反正切值 |
| **FLOOR** | int/float value | 与参数类型对应的向下取整 |
| **CEIL** | int/float value | 与参数类型对应的向上取整 |
| **ROUND** | int/float value | 与参数类型对应的四舍五入 |

### API

``` { #language-erbapi }
int/float SIN angle
int/float COS angle
int/float TAN angle
int/float ASIN value
int/float ACOS value
int/float ATAN value
int/float FLOOR value
int/float CEIL value
int/float ROUND value
```

C# 原生数学函数，提供三角函数与端数处理功能。

**同名重载**：
* 函数名不区分 Int/Float 版本（无 F 后缀变体）。
* 当至少一个参数为 Float 类型时，返回值自动为 Float；全为 Int 时返回 Int。
* 与运算符重载一致：`1 + 2.0` 返回 Float，`SIN(1.0)` 返回 Float。

**三角函数**（SIN/COS/TAN 及反函数）：
* 参数均为**弧度制**。如需角度转弧度，使用 `angle * PI() / 180`。
* ASIN/ACOS 的参数必须在 `[-1, 1]` 范围内，超出时抛出错误。
* Int 版本返回截断小数后的整数值（如 `SIN(1) = 0`，因为 sin(1 rad) ≈ 0.84 → 截断为 0）。
* Float 版本返回完整的 double 精度浮点数。

**端数处理**（FLOOR/CEIL/ROUND）：
* FLOOR：向下取整（向负无穷方向）。
* CEIL：向上取整（向正无穷方向）。
* ROUND：四舍五入，使用 `MidpointRounding.AwayFromZero`（.5 向远离零的方向舍入）。
* Int 版本对整数参数无实际效果（整数本身已是整数），主要供语义完整性使用。
* Float 版本返回浮点数结果。

### Hint

!!! hint "Hint"

    **表达式函数。**

    所有函数均为式中函数（表达式内使用），不支持命令语法。

    三角函数参数为弧度制。常用转换：
    ```
    ; 角度转弧度
    #DIM angle = 45
    #DIMF rad = angle * PI() / 180
    ; 计算 sin(45°) — Float 参数自动返回 Float 结果
    #DIMF result = SIN(rad)
    ```

    同名重载：Int 参数返回 Int，Float 参数返回 Float。无需使用 F 后缀。

### Example

**MAIN.ERB**
```erb
@SYSTEM_TITLE
    ; 三角函数（弧度制，Int 参数返回 Int）
    PRINTFORML SIN(1) = {SIN(1)}
    PRINTFORML COS(1) = {COS(1)}
    PRINTFORML TAN(1) = {TAN(1)}
    
    ; Float 版本（Float 参数自动返回 Float）
    #DIMF rad = 0.7853981633974483  ; PI/4 ≈ 45°
    PRINTFORML SIN(rad) = {SIN(rad)}
    PRINTFORML COS(rad) = {COS(rad)}
    
    ; 反三角函数
    PRINTFORML ASIN(0) = {ASIN(0)}
    PRINTFORML ACOS(0) = {ACOS(0)}
    PRINTFORML ATAN(1) = {ATAN(1)}
    
    ; 端数处理
    PRINTFORML FLOOR(3) = {FLOOR(3)}
    PRINTFORML CEIL(3) = {CEIL(3)}
    PRINTFORML ROUND(3) = {ROUND(3)}
    
    ; Float 端数处理
    #DIMF val = 3.7
    PRINTFORML FLOOR(val) = {FLOOR(val)}
    PRINTFORML CEIL(val) = {CEIL(val)}
    PRINTFORML ROUND(val) = {ROUND(val)}
```
``` title="结果"
SIN(1) = 0
COS(1) = 0
TAN(1) = 1
SIN(rad) = 0.707106781186548
COS(rad) = 0.707106781186548
ASIN(0) = 0
ACOS(0) = 1
ATAN(1) = 0
FLOOR(3) = 3
CEIL(3) = 3
ROUND(3) = 3
FLOOR(val) = 3
CEIL(val) = 4
ROUND(val) = 4
```
