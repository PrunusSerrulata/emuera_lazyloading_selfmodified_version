C# 原生数学函数，提供三角函数与端数处理功能。

**三角函数**（SIN/COS/TAN 及反函数）：
* 参数均为**弧度制**。如需角度转弧度，使用 `angle * PI() / 180`。
* ASIN/ACOS 的参数必须在 `[-1, 1]` 范围内，超出时抛出错误。
* Int 版本返回截断小数后的整数值（如 `SIN(1) = 0`，因为 sin(1 rad) ≈ 0.84 → 截断为 0）。
* Float 版本（SINF/COSF 等）返回完整的 double 精度浮点数。

**端数处理**（FLOOR/CEIL/ROUND）：
* FLOOR：向下取整（向负无穷方向）。
* CEIL：向上取整（向正无穷方向）。
* ROUND：四舍五入，使用 `MidpointRounding.AwayFromZero`（.5 向远离零的方向舍入）。
* Int 版本对整数参数无实际效果（整数本身已是整数），主要供语义完整性使用。
* Float 版本（FLOORF/CEILF/ROUNDF）返回浮点数结果。

### Hint

!!! hint "Hint"

    **式中関数。**

    所有函数均为式中函数（表达式内使用），不支持命令语法。

    三角函数参数为弧度制。常用转换：
    ```
    ; 角度转弧度
    #DIM angle = 45
    #DIM rad = angle * PI() / 180
    ; 计算 sin(45°)
    #DIMF result = SINF(rad)
    ```

    Float 版本接受 Int 或 Float 参数，Int 自动隐式转换为 Float。

### Example

**MAIN.ERB**
```erb
@SYSTEM_TITLE
    ; 三角函数（弧度制）
    PRINTFORML SIN(1) = {SIN(1)}
    PRINTFORML COS(1) = {COS(1)}
    PRINTFORML TAN(1) = {TAN(1)}
    
    ; Float 版本
    #DIMF rad = 0.7853981633974483  ; PI/4 ≈ 45°
    PRINTFORML SINF(rad) = {SINF(rad)}
    PRINTFORML COSF(rad) = {COSF(rad)}
    
    ; 反三角函数
    PRINTFORML ASIN(0) = {ASIN(0)}
    PRINTFORML ACOS(0) = {ACOS(0)}
    PRINTFORML ATAN(1) = {ATAN(1)}
    
    ; 端数处理
    PRINTFORML FLOOR(3) = {FLOOR(3)}
    PRINTFORML CEIL(3) = {CEIL(3)}
    PRINTFORML ROUND(3) = {ROUND(3)}
    
    ; Float 端数处理
    #DIMF val = 3.7
    PRINTFORML FLOORF(val) = {FLOORF(val)}
    PRINTFORML CEILF(val) = {CEILF(val)}
    PRINTFORML ROUNDF(val) = {ROUNDF(val)}
```

``` title="结果"
SIN(1) = 0

ASIN(0) = 0
ACOS(0) = 1
ATAN(1) = 0
FLOOR(3) = 3
CEIL(3) = 3
ROUND(3) = 3
FLOORF(val) = 3
CEILF(val) = 4
ROUNDF(val) = 4
```
