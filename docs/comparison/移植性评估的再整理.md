## 七、待办移植任务清单

以下是**尚未开始**但已列入移植手册或评估建议的任务：

### 1. 图形系统 (🔴 P0 - 🟡 P1)
*   [ ] **Stopwatch 计时重构**：修改 `SpriteAnime.cs` 和 `EmueraConsole.cs`，使用 `Stopwatch.GetTimestamp()` 替代 `DateTime.Now`。
*   [ ] **图像翻转逻辑**：在 `ASpriteSingle.GraphicsDraw` 中加入 `canvas.Scale(sx, sy)` 逻辑。
*   [ ] **多边形指令集**：移植 `G_POLYGON` 相关 4 个指令及其在 `GraphicsImage.cs` 中的顶点管理逻辑。
*   [ ] **装饰线渲染**：在 `ConsoleStyledString.cs` 中实现 `HasUnderline` 与 `HasStrikeout`。
*   [ ] **过时 API 修复**：清理 3 处 `SKPaint.TextAlign` 的警告。

### 2. 底层架构 (🟡 P1)
*   [ ] **并行加载集成**：将 DotNet 的 `AsParallel().ForAll()` 引入 `ErbLoader.cs`，与现有懒加载的 `Contains(file)` 跳过逻辑组合。
*   [ ] **SQL 便利性函数**：在 `SqlManager.cs` 中新增 `SQL_CONNECTION_OPEN`，自动映射路径。
*   [ ] **SQL 泛型重构**：引入内部泛型方法，合并 Long/String/Float 的标量查询代码。

### 3. 配置与杂项 (🟢 P2)
*   [ ] **JSON 配置支持**：引入 `System.Text.Json`，实现对 `setting.json` 的读取支持，尝试与现有的 XML 配置并存。
